# KnowledgeApp C#版のFAQ支援

このソースはC#正式版向けです。Windowsの既知フォルダーから解決した`%LOCALAPPDATA%\jp.local.webknowledgesystem.csharp`だけへ接続し、旧Tauri版と試作検証環境には接続しません。分類カタログまたは利用者が明示したFAQ・メール委譲番号だけを読み、確認待ちの提案だけを返します。DB、未選択FAQ、メール原本、添付画像本体は探索しません。

## 切り替え後の使い方

1. C#版を起動します。既存FAQ・メールから依頼する場合は、C#版の画面で対象を選択・確認し、新しい委譲番号を発行します。
2. このリポジトリのCodexタスクでは、`AGENTS.md`から参照される最新版の`skills/knowledgeapp-faq/SKILL.md`を直接使って依頼できます。新規FAQは提供内容と分類カタログだけ、修正・統合・メール由来案は指定した委譲だけが対象です。
3. リポジトリ外のタスクでインストール済みプラグインを使う場合は、C#対応版が適用されていることを確認し、新しいタスクで依頼します。ソースを変更しただけでは、既存タスクやインストール済みキャッシュの更新は保証されません。
4. C#版の「Codexからの提案」で内容を確認し、承認または却下します。送信だけではFAQの自動公開や既存FAQの更新は行いません。

旧版で作成した未処理の委譲・提案は自動移行しません。旧版の委譲番号が見つからない場合はC#版で再発行してください。旧版の提案箱へ届いたファイルを手動コピーして回避せず、対応スキル・プラグインを確認します。通常運用で`TestDataRoot`やテストモードを指定して保存先を変えてはいけません。

## 今回確認した範囲（2026-09-06）

PowerShell 7およびWindows PowerShell 5.1の実コマンドとC#サービスを、新規合成データだけで確認しました。分類取得、選択FAQ・選択メールの委譲取得、新規・修正・統合の提案送信、承認前非変更、版競合拒否、1MiB／5MiB境界、旧版へのフォールバック禁止を含みます。日時文字列とFAQ本文を保持する修正も維持しています。

実行環境では個人マーケットプレイスの登録ファイルがなく、`codex plugin list`にも登録済みプラグインが表示されませんでした。そのためソース更新・検証までとし、マーケットプレイス新設、プラグイン再導入、設定・キャッシュ変更は実行していません。インストール済みプラグインを使った実AI往復の合格とは区別します。

提案形式・許可ノード・画像と外部資料の境界は、`skills/knowledgeapp-faq/references/proposal-format.md`を参照してください。
