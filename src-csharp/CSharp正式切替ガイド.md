# C# 0.5.0 正式切替ガイド

2026-09-06。今後の開発・通常利用はC#を主系とします。画面は従来のReact/Tiptap/CSSを維持しています。

## 最初の引継ぎ（各PCで1回）

1. 旧版KnowledgeAppへログインし、「設定・情報」→「フルバックアップを作成」で新しい`.faqbackup`をリポジトリ外へ保存します。完了後、旧版を通常終了します。
2. `KnowledgeApp-CSharp-0.5.0-setup.exe`でC#版を導入し、スタートメニューの **KnowledgeApp (C#)** を起動します。旧版とは別のアプリです。
3. 初回だけログインID`0000`・パスワード空欄でログインします。C#側が既に初期化済みなら、そのC#側の認証を使用します。
4. C#の「設定・情報」→「バックアップから復元」で手順1のファイルを選び、件数と内容のプレビューを確認して復元します。現在のC#側は置き換わるため、C#側にも必要なデータがあれば先にバックアップしてください。通常の復元前安全退避も自動作成されます。
5. 復元後は旧版で使っていたID・パスワードでログインし、FAQ件数と代表1件の本文・画像を確認してください。確認後はC#側だけで編集します。

ログイン操作はご本人にお願いします。バックアップはFAQ・画像・設定・利用者情報を含むため、会社規定に沿う保存先で保管してください。CodexにDBやバックアップ内容を直接提示する必要はありません。

## 保存先と戻し方

| 用途 | OSのLocalApplicationData配下 |
|---|---|
| C#本番の正本 | `jp.local.webknowledgesystem.csharp` |
| 旧Tauri・切替前の退避状態 | `jp.local.webknowledgesystem` |
| 開発試験（`--rehearsal`） | `jp.local.webknowledgesystem.csharp-rehearsal` |

旧版の導入先・データは変更しません。ただし旧版を開いても切替後のC#更新は自動では反映されません。戻す必要が生じた場合はまずC#で最新のフルバックアップを作り、旧版側でも現状を退避してから旧版の通常復元で戻してください。DBの直置き・二つのアプリでの並行編集は避けてください。

C#の起動時・復元前には専用ルート内へ安全バックアップを作ります。更新やアンインストールはC#の実行物だけが対象で、FAQデータは消しません。異常終了後の復旧案内が出た場合は案内に従い、データフォルダーを削除しないでください。

## Codexへの依頼

このリポジトリのタスクではAGENTS.mdから更新済みの専用スキルを読んで、C#のカタログ・明示委譲番号だけを使用します。旧版からコピーした委譲文は再利用せず、C#側で番号を発行し直してください。別タスクで導入済みの古いプラグインはC#へ自動接続されません。[プラグインの案内](../codex-plugins/knowledgeapp-faq/README.md)を確認してください。

この切替作業ではFAQをAIへ自動送信しません。メールもボタン操作による明示走査・選択・マスク・専用委譲だけを維持します。

## 会社PCで残す確認

会社規定上の実行許可、WebView2/.NET Runtime、画面倍率、ローカル保存とバックアップ先は会社PCで確認してください。既存の段階テストを全件やり直す必要はありません。16MiB超の要求、通常JSONの極深構造、`.pst`対応、管理ID衝突の運用改善、暫定緊急認証の置換などは後続改修として扱います。
